# Data Platform Registry

This repository tracks the data platform team's published data assets and community requests.

## Overview

The team publishes **derived data assets** on the public data hub. Derived assets are built by cleaning and combining **upstream source assets**. The registry (`assets/catalog.json`) lists every published asset, its type (upstream or derived), its declared license and — for derived assets — the upstream sources it was built from.

## Published data assets

- Product Sentiment Dataset (derived)
- Financial News Summaries (derived)
- Retail Review Corpus (upstream)
- Social Media Feed (upstream)
- Financial News Corpus (upstream)

## Documentation

Provenance and reuse terms for the published assets are documented in `docs/reuse_terms.md`.

## Issues

Community requests and questions about the published assets are tracked as issues in this repository.
